# Power BI Tasks

This repository contains a collection of Power BI tasks, dashboards, and data visualization projects created to practice and enhance business intelligence and data analytics skills. The tasks cover data cleaning, data modeling, DAX calculations, interactive dashboard design, KPI tracking, and report generation using Power BI.

## Topics Covered

* Data Import and Transformation (Power Query)
* Data Modeling and Relationships
* DAX Measures and Calculated Columns
* Interactive Dashboards
* KPI and Performance Analysis
* Sales and Business Analytics
* Data Visualization Best Practices

## Purpose

The objective of this repository is to demonstrate practical Power BI skills through hands-on projects and real-world datasets. Each task focuses on transforming raw data into meaningful insights that support data-driven decision-making.

## Tools Used

* Power BI Desktop
* Power Query
* DAX (Data Analysis Expressions)
* Excel / CSV Datasets

This repository serves as a portfolio of Power BI projects and learning exercises for data analytics and business intelligence.
